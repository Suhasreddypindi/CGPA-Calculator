# GPA / CGPA Calculator

## About

This is a simple GPA and CGPA Calculator made using **HTML, CSS, and JavaScript**.

The project allows students to:

* Add subjects
* Enter credits and grade points
* Calculate semester GPA
* Calculate overall CGPA
* Predict future CGPA using the "What If" feature

## Features

* Add multiple subjects
* Calculate Semester GPA
* Calculate Overall CGPA
* Predict future CGPA

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Open the `index.html` file in a web browser.
2. Enter the credit and grade point for each subject.
3. Click **Add** to save each subject.
4. Click **Calculate GPA** to see your semester GPA.
5. Enter your previous CGPA and completed credits.
6. Click **Calculate CGPA** to see your updated CGPA.
7. Enter your expected future GPA and future credits.
8. Click **Predict** to estimate your final CGPA.

## Project Files

* `index.html` – Main webpage
* `style.css` – Styling
* `script.js` – GPA and CGPA calculations
